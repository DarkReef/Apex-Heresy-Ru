# Аудит интерфейса и кода Apex Heresy RU — 6 октября 2026

Область: интерфейс системы для Foundry VTT 14. Книги, компендиумы и их переводы Babele в этом изменении не редактировались. Модули остаются в отдельных репозиториях.

## Выполнено

- Переведены ранее встроенные английские строки настроек, всех 21 пресета погоды/местоположения, температуры, гравитации и радиации, единиц измерения, подсказок листов, уведомлений миграции и применения урона.
- Интерфейсный словарь: 1980 ключей, русский и английский наборы совпадают; параметры подстановки проверяются тестами.
- Добавлена команда npm run localization:interface. Она собирает интерфейс и его отчёт покрытия, не открывая и не пересобирая базы компендиумов.
- Регистрация системных настроек вынесена из монолитного файла в script/settings.mjs; имена сохранённых настроек, типы, области действия и значения по умолчанию сохранены.
- Окно окружения перенесено с Application V1 на ApplicationV2 + HandlebarsApplicationMixin. Удалена неиспользуемая ветка редактирования групп сцен. Окружение сохраняется во флаге конкретной сцены.
- Запись параметров окружения выполняется последовательно: соседние правки больше не перезаписывают друг друга старым состоянием. Проверяется право ведущего; ошибки записи отображаются пользователю.
- Исправлено форматирование малых доз: 1.2e-10 больше не превращается в 1.2e-1 при удалении хвостовых нулей.
- Нормализуются отрицательная гравитация, бесконечные дозы, неизвестные единицы и пресеты, некорректные текстовые значения. Ключи прототипа не принимаются за пресет.
- Пользовательские заметки и произвольные названия погоды не переводятся и экранируются при выводе в HTML.

## Проверка

- Полный набор: 896 тестов, 894 прошли, 2 штатно пропущены, ошибок нет.
- Все 93 шаблона прошли разбор Handlebars.
- На браузерном стенде использованы реальные шаблон, стили и код окна; проверены русский интерфейс, смена погоды, отображение радиации и сохранение гравитации.
- Стенд имитирует API Foundry. Работа в настоящем мире, права подключённых игроков и взаимодействие с включёнными модулями в этой итерации не проверены.

## Остаток технического долга

Базовые листы DarkHeresySheet и DarkHeresyItemSheet, а также унаследованные листы техники по-прежнему используют foundry.appv1.sheets. Это действующий слой совместимости целевой версии 14, но он требует отдельной миграции на DocumentSheetV2 с проверкой сохранения форм, перетаскивания и встроенных предметов. Адаптер dhDialog уже использует DialogV2, но сохраняет старый jQuery-контракт для обработчиков. Полная миграция всех листов здесь не выполнена; заявление об отсутствии всех ошибок в системе не делается.

Механические таблицы, правило ран и пользовательские данные мира не менялись. Для завершения приёмки нужен запуск в реальном Foundry 14: открыть окно окружения, последовательно изменить все категории, перезагрузить сцену и проверить виджет у игрока.

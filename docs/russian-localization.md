* Переведены все 1 855 ключей `lang/en.json`. Динамические параметры сообщений сохранены.
* Babele подключается через `babele.init` и `setSystemTranslationsDir`. Каталоги находятся в `localization/ru`.
* Переведены названия 994 записей и 646 описаний документов. Компендиум **Only War завершён**: 498 названий и описаний, 175 текстов преимуществ, 35 кратких описаний психосил и все папки. Переведены шесть связанных таблиц со всеми 91 результатами. Названия 59 происхождений Only War приведены к приложенной русской книге. [Подробности и источники Only War](only-war-localization.md). В «Происхождениях» переведены названия и описания всех 134 записей; также переведены названия всех 74 таблиц.
* Остаются непереведённые названия, описания, результаты таблиц и текст, непосредственно зашитый в JavaScript и шаблоны. Точное покрытие и список недостающих полей, включая результаты таблиц: `localization/ru/coverage.json`.

## Установка из исходников

1. Сохраните резервную копию мира. Остановите Foundry.
2. Скопируйте содержимое этого репозитория в `Data/systems/dark-heresy`. ID системы сохраняется для совместимости с существующими мирами.
3. Запустите Foundry, установите русский язык интерфейса.
4. Установите Babele и его зависимости, включите Babele в настройках модулей мира.
5. Перезагрузите мир. Если Babele уже работал с этим миром, очистите его кэш переводов через настройки модуля.

Без Babele переводится языковой файл интерфейса. Компендиумы переводит Babele. Уже созданные в мире предметы автоматически не переписываются; они остаются пользовательскими документами.

Ссылки манифеста теперь ведут в этот форк. Установщик по манифесту станет доступен после публикации релиза с `apex-heresy-ru.zip`. Workflow `Russian fork release` запускается вручную; автоматически этот этап переводов не публикуется.

## Сохранение механики

ID документов, UUID, ID системы и названия коллекций сохраняются. Исходные базы `packs/` не изменяются.

Babele переводит отображаемые названия и отдельные текстовые поля. Он не переводит `special`, `aptitudes`, `grants`, ключи, формулы, значения перечислений и требования `prerequisites`/`prerequisite`: система читает эти поля при применении правил. Для русских названий поиск и расчёты используют исходное имя Babele (`originalName` или `flags.babele.originalName`). Числовые особенности, склонности, санкционированность псайкера и исключение уже купленных талантов покрыты регрессионными тестами.

## Продолжение перевода

`glossary.json` содержит проверенные соответствия строк. `entries.json` содержит переводы по стабильному ID и паку; это позволяет различать одноимённые таланты разных книг с разными правилами. Не заменяйте описание таланта другой редакцией: например, предел повторных покупок «Крепкого телосложения» в DH2 и Black Crusade различается.

```sh
npm ci --ignore-scripts
npm run localization:build
npm test
```

Генератор открывает временные копии LevelDB: простое открытие оригинальной базы иначе меняет её служебные файлы. Покрытие считает только реально переведённые поля; английские заготовки не считаются переводом. Результаты таблиц добавляются отдельно с сохранением диапазонов, весов, формул и ссылок на документы. Покрытие теперь также учитывает преимущества и краткие описания, а не только название и основной текст. Контекстные названия папок задаются в `pack-folders.json`.

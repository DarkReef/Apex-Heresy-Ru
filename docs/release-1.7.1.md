# Apex Heresy RU 1.7.1 — кандидат проверки стабильности

Исправлена потеря полей расширений после перезагрузки: модели регистрируются синхронно, ItemPileFFG получает событие до создания документов, миграция учитывает реальную схему подкласса. Старые архивные значения автоматически не перезаписывают текущие данные.

Новый нативный срок состояния очищает предыдущий собственный таймер; выключение эффекта не продлевает абсолютный срок; потеря роли активного GM оставляет неисполненный запрос следующему GM. Сохранённые квитанции предотвращают повторное применение операции. Служебный журнал боевых запросов скрыт до добавления обычных кнопок урона и лечения.

Ускорены подготовка VM для unit-тестов и синтаксическая проверка. Добавлены отдельные наборы TDD, измерение V8/LCOV с настоящим основным entry и артефакты CI Node 22/24. Две прежние проверки пакетов больше не пропускаются из-за абсолютного пути к Foundry.

Для передачи рюкзаков через Item Piles 3.3.4 требуется отдельный **ItemPileFFG 0.2.4**, исправляющий формат запроса и раннюю регистрацию полей. **Charbar 0.1.6** обновляет результаты в исходном запросе без отдельной карточки; для этого системный API получил параметр `chat:false`. Smart Assessment 0.4.0 проверен без изменений. Модули остаются отдельными пакетами.

Состав, результаты живой проверки, ограничения сторонних модулей и решение о stable зафиксированы в [отчёте аудита](stability-audit-2026-11-05.md). До закрытия критических пунктов приёмки этот выпуск остаётся кандидатом.

# Русский перевод Only War

Перевод компендиума `dark-heresy.only-war` завершён. Терминология взята из предоставленного пользователем PDF «Only War (Базовая книга правил) (Rus 1.05)-3.pdf». Русские описания сверены с исходным содержимым компендиума; ошибки извлечения и соседние разделы, случайно попавшие в английские записи, убраны.

| Содержимое | Переведено |
| --- | ---: |
| Названия и описания записей | 498 из 498 |
| Преимущества талантов и особенностей | 175 из 175 |
| Краткие описания проверок психосил | 35 из 35 |
| Папки | Все 43 уникальных названия |
| Происхождения Only War | Названия всех 59 сверены с книгой; описания переведены ранее |
| Связанные таблицы | 6 таблиц, все 91 результата |

Таблицы: случайное снаряжение, эффекты жути, критические попадания по оружию, ходовой части, башне и корпусу. Они находятся в общем паке `bc-tables`. Общие таблицы из других книг, которые система также использует, относятся к оставшейся работе по всему форку.

Названия привязаны к ID и паку, чтобы термины этой книги не заменяли одноимённые записи другой игры. Например: «Акимбо», «Бронник», «Плазмомёт», «Погибельный вихрь», «Нетопыри», «Упрямец», «Водитель», «Военный врач». Характеристики в русском интерфейсе называются «Дальний бой» и «Товарищество».

## Сохранённые правила

В нескольких местах русский PDF опускает правило или расходится с исходным компендиумом. Для правил сохранено содержание исходных записей; PDF определяет названия и термины:

- Силовой кулак добавляет удвоенный бонус Силы.
- Подствольный гранатомёт имеет дальность 45 м, как в исходном компендиуме; русский PDF приводит 30 м.
- Фотонная граната действует в пределах 15 м.
- Описание галлюциногенной гранаты включает тест Выносливости, радиус и длительность.
- Усиление пси-рейтинга жутью действует один час.
- «Ясновиденье» включает результаты для 1, 2, 3 и 4+ ступеней успеха.
- Защитные поля включают общие правила нейтрализации атак и перегрузки.
- Подгонка оружия включает ограничение на полковое снаряжение, четыре модификации и тест оружейника.

Из описаний «Варп-блока», «Сокрушительного удара», «Имплантатов Механикус» и ряда психосил исключены чужие разделы, приклеенные при извлечении английского текста. ID документов, UUID, формулы, эффекты, характеристики, требования и исходные базы не меняются.

`only-war-sources.json` связывает все 498 документов с английским именем, русским заголовком и страницей PDF либо исходной ссылкой. Страница PDF указана по физической нумерации файла; она может отличаться от номера английского издания в `system.source`. Сам PDF не включён в репозиторий.

## Отображение технических полей

Babele переводит имена и текстовые поля. Требования, склонности, формулы и свойства, которые читает движок, хранятся в исходном виде. Помощник `ruleText` переводит их при показе в чат-карточке Only War, в списке оружия и в проверках требований мастера создания персонажа. Редактируемые технические поля листа предмета сохраняют исходные значения. Помощник не меняет расчёты и не применяется к другим книгам или английскому интерфейсу.

`only-war-rule-terms.json` содержит термины для отображения; генератор добавляет названия из компендиума в `script/localization/only-war-terms.mjs`. Для обновления достаточно `npm run localization:build`.

## Проверка

`npm run localization:test` проверяет полный охват 498 записей по временной копии исходной LevelDB, все непустые текстовые поля, баланс HTML, терминологию, сохранение исходных имён для механики и формулы всех 91 результата таблиц. `npm test` запускает также общие регрессионные проверки системы.

Запуск в реальном Foundry VTT 14 с Babele пока не проверен. Завершён перевод содержимого компендиума Only War; это не утверждение о завершении русификации всего форка или аудита правил движка Only War.

# Apex Heresy RU 1.6.1

При наведении на характеристику или навык видны величина модификатора и источник: база, развитие, ручные изменения и действующие эффекты экипировки. Например, `+10 — Броня Авенджер`. Значения подсказок не записываются в данные персонажа.

Магазин оружия подключается к конкретным боеприпасам инвентаря, включая вложенные рюкзаки. В карточке показаны запас, контейнер и текущий заряженный профиль. Выстрел расходует магазин, перезарядка берёт запас; можно учитывать патроны или целые магазины/ячейки. Добавлен отдельный модификатор ББ: бронебойные патроны с `+2` добавляют 2 к бронебойности оружия. Заряженные свойства сохраняются при смене привязки и удалении запаса.

Убраны поиск оружия по совпадению имени и запись расхода непривязанного токена в базового актёра. Перезарядка обновляет оба предмета одним пакетом; повторные локальные действия упорядочены. Старое окно атаки после смены заряженного профиля просит открыть бросок заново. Переброс за Судьбу не расходует магазин повторно.

Для передачи комплектов с сохранением связей обновите **ItemPileFFG до 0.2.3**. [Инструкция по настройке](https://github.com/DarkReef/Apex-Heresy-Ru/blob/main/docs/ammunition-modifiers.md).

ID пакета остаётся `apex-heresy-ru`, обновления идут из этого репозитория. Для перехода с 1.5.x по-прежнему нужен [однократный перенос мира](https://github.com/DarkReef/Apex-Heresy-Ru/blob/main/docs/package-identity-migration.md). Книги-компендиумы не редактировались.

Проверки: 973 автоматических теста системы прошли, 2 пропущены; 42 проверки ItemPileFFG прошли. Новые поля проверены на настоящих моделях Foundry 14.368, шаблоны скомпилированы и просмотрены на тестовых данных. Полный многопользовательский прогон в живом мире ещё требуется; пользовательские базы при подготовке выпуска не менялись.

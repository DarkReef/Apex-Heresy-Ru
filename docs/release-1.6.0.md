# Apex Heresy RU 1.6.0

Пакет получил собственный ID `apex-heresy-ru`. Это устраняет коллизию с Vendare Dark Heresy 2E, из-за которой Foundry 14 выбирал чужую систему при обновлении.

**Существующим мирам нужен однократный перенос.** Сначала полная резервная копия, затем отдельная установка системы и изменение привязки конкретного мира помощником `Move-ApexWorld.ps1`. [Инструкция](https://github.com/DarkReef/Apex-Heresy-Ru/blob/codex/apex-package-identity/docs/package-identity-migration.md). Если мир уже запускался в Vendare, нужна копия до чужой миграции; этот выпуск её не отменяет.

Сохраняются настройки, выбранные правила, флаги, контейнеры, API и ID документов. Перенос обновляет ссылки на ресурсы и компендиумы; пользовательский код макросов не меняет. Для расширений нужны ItemPileFFG 0.2.2, Riftan Charbar 0.1.5 и Riftan Smart Assessment 0.3.1 либо новее.

Оригинальный Apex Heresy проверен: новых изменений после upstream 1.4.2 (`b71f257`) нет. В выпуск включена база 1.5.6 RU с подтверждением урона OW. Книги и игровые правила не переписывались.

Проверки: 937 автоматических тестов прошли, 2 пропущены; отдельно 51 проверка помощника переноса. Новый manifest, сохранённые флаги и обход вложенных документов проверены на настоящих классах Foundry 14.368 с синтетическими данными в памяти. Проверка в живом многопользовательском мире ещё требуется; пользовательские базы при подготовке выпуска не изменялись.

# Модификаторы и боеприпасы

## Источники модификаторов

Наведите указатель на итоговое значение характеристики или навыка. Подсказка показывает базу, развитие, ручной модификатор и действующие эффекты с названиями источников, например `+10 — Броня Авенджер`. Для навыка также показаны вклад характеристики и подготовка. Итог доступен с клавиатуры.

Выключенные и подавленные эффекты не учитываются. Если изменение нельзя достоверно разложить по источникам, подсказка показывает остаток «Прочие изменения», сохраняя фактический итог листа. Подсказки не меняют значения и не записывают бонусы экипировки в ручное поле.

## Подключение магазина

1. Добавьте персонажу предмет типа «Боеприпасы». Он может лежать в рюкзаке или во вложенном контейнере.
2. Укажите совместимый тип/класс оружия, количество и единицу учёта: магазины/энергоячейки либо отдельные патроны. Старые предметы сохраняют учёт магазинами/ячейками.
3. В карточке оружия, на вкладке данных, выберите запас в слоте «Боеприпасы магазина» либо перетащите туда предмет из инвентаря этого персонажа. Слот показывает остаток и путь к контейнеру; кнопка рядом открывает выбранный предмет.
4. Перезарядите оружие. Выстрел расходует патроны в магазине оружия; перезарядка списывает запас из подключённого предмета. При учёте патронами списывается необходимое доступное количество, при учёте магазинами — одна единица. Полный магазин не расходует запас.

Смена привязки не меняет уже заряженные патроны: ниже слота отдельно показан текущий профиль магазина. Чтобы зарядить другой вид, сначала опустошите магазин. При первой привязке уже заряженного оружия его прежний профиль также сохраняется; ручное изменение числа патронов само по себе не выполняет перезарядку. При пустой привязке сохраняется прежний автоматический подбор совместимых боеприпасов.

Свойства заряженных патронов сохраняются при удалении или редактировании запаса. Если профиль изменился после открытия окна атаки, система попросит открыть бросок заново, чтобы использовать актуальные свойства. Переброс за Судьбу не списывает боеприпасы повторно.

## Бронебойные патроны

Для бонуса `+2 к ББ` у боеприпаса задайте **модификатор бронебойности = 2**, оставив поле замены бронебойности пустым. После перезарядки оружие с ББ 3 получит ББ 5. Старое поле бронебойности сохраняет смысл полной замены, включая значение 0. Поля урона, точности и особых свойств работают по существующим правилам профиля боеприпасов.

## Перенос и совместимость

ItemPileFFG 0.2.3 переносит связи оружия с запасами при копировании и передаче комплектов. Если передаётся только оружие, его заряженные патроны сохраняются, а ссылка на запас прежнего владельца очищается. Различающиеся профили и единицы учёта не объединяются в одну стопку.

Действия с непривязанным токеном изменяют его собственный инвентарь, не базового актёра и не одноимённые предметы другого персонажа. Перезарядка обновляет оружие и запас одним пакетом; операции одного клиента упорядочены. Это не межклиентская транзакция: одновременное управление одним оружием с двух клиентов требует отдельной проверки в игре.
